# Bash Terminal Configuration in OpenSUSE Tumbleweed

Bash shell configuration is modularized under `Bash.Setup/`:

- `aliases.sh`: Shortcuts for `zypper` (`update`, `dup`, `install`, `remove`, `clean`), `snapper`, and Rust tools (`eza`, `bat`, `duf`, `dust`).
- `environment.sh`: Global `PATH`, `EDITOR`, and pager settings.
- `functions.sh`: Advanced functions and multimedia tools.
- `gnome_settings.sh`: GNOME Shell shortcuts and control.
- `history.sh`: History management.
- `options.sh`: Bash shell options (`shopt`).
- `podman-functions.sh`: Container management.
- `rclone_aliases.sh`: Google Drive sync.
- `yt-dlp_aliases.sh`: Multimedia downloads.
