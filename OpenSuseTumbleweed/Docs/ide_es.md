# Entornos de Desarrollo (IDEs) en OpenSUSE Tumbleweed

Esta guía describe los editores e IDEs configurados en la carpeta `IDE/`.

---

## 1. Neovim + LazyVim (`neovim.sh`)

Instalación de Neovim con LazyVim y herramientas de soporte:

```bash
just nvim
```

---

## 2. Visual Studio Code (`vscode.sh`)

Instalación desde el repositorio RPM oficial de Microsoft configurado con Zypper:

```bash
just vscode
```

---

## 3. Google Antigravity Desktop 2.0 (`antigravity.sh`)

Instalación de la plataforma de desarrollo con asistentes de inteligencia artificial:

```bash
just antigravity
```

---

## 4. Antigravity CLI & IDE Engine (`antigravity-cli.sh`, `antigravity-ide.sh`)

```bash
just antigravity-cli
just antigravity-ide
```

---

## 5. OpenCode AI (`opencode.sh`)

Editor/CLI asistido por inteligencia artificial:

```bash
just opencode
```
