# Applications & Gaming in OpenSUSE Tumbleweed

This guide details desktop applications and gaming platforms configured in `Setup` and `Juegos`.

---

## 1. Meld: Visual Diff Tool

* **Installation**:
  ```bash
  sudo zypper install -y meld
  ```

## 2. Steam & Proton-GE (`steam.sh`)

Steam is available via native Zypper package or Flathub, with **Proton-GE** compatibility tool:

```bash
just steam
```
