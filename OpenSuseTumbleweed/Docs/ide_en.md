# Development Environments (IDEs) in OpenSUSE Tumbleweed

This guide describes development tools configured in `IDE/`.

---

## 1. Neovim + LazyVim (`neovim.sh`)

```bash
just nvim
```

---

## 2. Visual Studio Code (`vscode.sh`)

Installed from Microsoft's official RPM repository via Zypper:

```bash
just vscode
```

---

## 3. Google Antigravity Desktop & CLI Suite

```bash
just antigravity
just antigravity-cli
just antigravity-ide
```

---

## 4. OpenCode AI (`opencode.sh`)

```bash
just opencode
```
