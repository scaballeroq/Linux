# Linux Monorepo

Repositorio unificado que centraliza configuraciones, scripts de automatización, perfiles de entorno y dotfiles para múltiples distribuciones Linux.

## Distribuciones y Entornos Incluidos

| Directorio | Descripción / Entorno |
| :--- | :--- |
| `ArchLinux` | Configuración base y personalización de Arch Linux |
| `ArchLinux-Niri-DMS` | Arch Linux con compositor Niri y gestión de pantalla DMS |
| `CachyOS` | CachyOS con optimizaciones de rendimiento y kernel |
| `CachyOS-Niri-DMS` | CachyOS con compositor Niri y entorno DMS |
| `CachyOS_Niri_Noctalia` | CachyOS con Niri y configuración personalizada Noctalia |
| `Debian` | Debian GNU/Linux estable y personalización general |
| `DebianTesting` | Debian Testing con configuraciones actualizadas y scripts de setup |
| `Fedora` | Fedora Workstation y herramientas del sistema |
| `Fedora-Workstation` | Fedora Workstation con scripts de configuración para desarrollo |
| `KDEDebian` | Debian con entorno de escritorio KDE Plasma |
| `KDEDebianTesting` | Debian Testing optimizado para KDE Plasma 6 |
| `Kubuntu` | Kubuntu con entorno de escritorio KDE Plasma |
| `Manjaro` | Manjaro Linux con herramientas de productividad y gaming |
| `NixOS` | NixOS declarativo con Flakes, perfiles de hardware y configuración del sistema |
| `Omarchy` | Configuración personalizada de entorno Arch Linux |
| `OpenSuseTumbleweed` | openSUSE Tumbleweed rolling release con Flatpak y herramientas |
| `SoplosLinuxTyson` | Configuración especializada Soplos Linux |
| `Ubuntu` | Ubuntu Linux con entorno GNOME y herramientas de desarrollo |

## Estructura

Cada subdirectorio conserva el historial completo de su respectivo repositorio independiente y contiene los scripts, configuraciones (`justfile`, `Bash.Setup`, `Docs`, etc.) y documentación específica.
