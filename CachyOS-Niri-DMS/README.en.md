# 🔧 Arch Linux Environment Configuration (Niri + Dank Material Shell)

An organized, modular, and automated collection of configuration and provisioning scripts for **Arch Linux** running the **Niri** scrollable-tiling Wayland compositor alongside the modern **Dank Material Shell (DMS)** desktop environment based on Material Design 3 (Material You).

---

## 🌟 Key Highlights

- **Distribution**: Pure Arch Linux (rolling release, official kernel, microcode, and optimized Pacman).
- **Compositor**: [Niri](https://github.com/YaLTeR/niri) (Rust scrollable-tiling Wayland window manager).
- **Desktop Shell**: [Dank Material Shell](https://danklinux.com/) (DMS) built on Quickshell and Material 3 principles:
  - Integrated top bar and responsive dock.
  - Application launcher, control center, and hardware quick settings (Wi-Fi, Bluetooth, brightness, audio).
  - Visual clipboard manager and session lock screen.
  - Complementary apps: `dankcalendar` (`dcal`), `danksearch`, and Greetd greeter.
  - Dynamic Material You theming generated by **Matugen** and applied across Kitty, GTK, and Niri.
- **Terminal & Shell**: GPU-accelerated **Kitty** emulator with Wayland blur and modular loader for **Zsh** and **Bash** (`~/.zshrc.d` and `~/.bashrc.d`), powered by the **Starship** prompt.
- **Containers**: **Podman Rootless** ecosystem integrated with **Systemd Quadlets**, project blueprints, and Docker socket compatibility for IDEs.
- **Virtualization**: **KVM / QEMU** setup optimized with Libvirt 12+ modular sockets, 3D VirGL, VirtioFS, and Niri window rules.
- **Development & AI Tools**: Google Antigravity Desktop, Antigravity CLI (`agy`), Antigravity IDE, OpenCode, VS Code, Neovim (LazyVim), Meld, and Gemini CLI.
- **Language Management**: Isolated runtimes managed via **Mise** (Node.js, Python, Rust, .NET SDK, OpenJDK, Angular).

## 📂 Repository Structure

The configuration is modularly organized for clarity and maintainability:

### ⚙️ [Setup](./Setup/)
Operating system setup, personalization, and security hardening scripts:
- **`post-install.sh`**: Intelligent CPU dispatcher (AMD Ryzen vs Intel Core).
- **`post-install-amd.sh`**: Post-installation for AMD Ryzen (AMD microcode, RADV, Mesa, PipeWire, Niri + DMS stack).
- **`post-install-intel.sh`**: Post-installation for Intel Core (Intel microcode, VA-API Intel, PipeWire, Niri + DMS stack).
- **`dms-setup.sh`**: Dank Material Shell management and health checker (`dms doctor`, systemd service, theme regeneration).
- **`backup-niri-dms.sh`**: Automated backup manager for Niri and DMS configs (create, list, restore).
- **`kitty.sh`**: GPU-accelerated Kitty configuration with opacity, blur, and Material You dynamic theme.
- **`shell.sh`**: Modern terminal utilities (`eza`, `bat`, `fd`, `zoxide`, `ripgrep`, `btop`, `jq`, `zsh`, `starship`).
- **`seguridad.sh`**: Firewalld setup (home LAN), QEMU/KVM integration, Podman, and Sysctl.
- **`cockpit.sh`**: Web management interface on-demand via systemd socket.
- **`fastfetch.sh`**: Aesthetic system information fetcher with custom JSON configuration.
- **`fonts.sh`**: Developer fonts (Nerd Fonts: JetBrainsMono, FiraCode, and Inter Variable).
- **`yt-dlp-setup.sh`**: Multimedia stack dependencies (yt-dlp, FFmpeg, Deno/Node).

### 🐚 [ZSH.Setup](./ZSH.Setup/)
Modular shell configuration for **Zsh** and **Bash**:
- **`aliases.sh`**: Navigation shortcuts (`arch`, `project`, `repo`), safety (`rm -i`), package management (`pacman` / `yay`), mirror ranking (`rate-mirrors`), and global pipes in Zsh (`G`, `L`, `H`, `J`).
- **`niri_dms.sh`**: Niri and Dank Material Shell IPC control (`dms ipc`), Wayland screenshots (`grim` + `slurp` + `satty`), and recording (`wl-screenrec`).
- **`environment.sh`**: Global environment variables (`EDITOR`, `PATH`, Wayland/Qt, Docker host) and Mise activation.
- **`functions.sh`**: Multimedia helpers, disk tools, universal extraction, and quick directory jumping (`mkcd`, `up`).
- **`history.sh`**: High-capacity history (50k entries, deduplication, instant sharing).
- **`options.sh`**: Internal shell behavior (`autocd`, typo correction, interactive menus).
- **`podman-functions.sh`**: Helper functions for Podman containers and Quadlets.
- **`rclone_aliases.sh`**: Cloud storage sync for Google Drive (`gdrive-arch`) and OneDrive.
- **`yt-dlp_aliases.sh`**: Media download helpers.

### 🐳 [Podman](./Podman/)
Rootless container ecosystem with native systemd Quadlets:
- **`install/podman-install.sh`**: Rootless Podman configuration, socket, linger, registries.
- **`install/quadlets-setup.sh`**: Systemd Quadlets directory and service manager.
- **`lib/podman-utils.sh`**: Complete CLI for managing projects and shared services.
- **`projects/`**: Directory for active projects.
- **`services-shared/`**: Global shared services (PostgreSQL, Redis, Traefik, Keycloak).
- **`templates/`**: Project templates (python-postgres, python-postgres-redis, fullstack).

### 🖥️ [Virtualizacion](./Virtualizacion/)
- **`virtualization.sh`**: KVM/QEMU setup, Libvirt modular sockets, VirGL 3D, VirtioFS, and Niri rules.
- **`notas_virtualizacion_arch.md`**: Detailed technical manual on virtualization in Arch Linux.

### 💻 [IDE](./IDE/), [Apps](./Apps/) & [AI](./AI/)

## 🚀 Quick Start with `just`

The repository provides a `justfile` that automates individual tasks or the complete installation:

```bash
# 1. Clone the repository
git clone https://github.com/scaballeroq/ArchLinux-Niri-DMS.git
cd ArchLinux-Niri-DMS

# 2. Install just if not already present
sudo pacman -S --needed just

# 3. Deploy full environment (CPU auto-detection)
just setup-all
```

### Specific Recipes:
```bash
just post-install        # Base system setup
just shell               # Shell tools & modular loader
just dms-setup           # DMS verification & service setup
just dms-doctor          # DMS health check
just security            # Firewalld, dev ports & sysctl
just kitty               # Kitty terminal with Material You theme
just git-setup           # Git, Git-Delta, Lazygit & GitHub CLI
just ides                # Antigravity Desktop, CLI, IDE & OpenCode
just languages           # All programming languages
just podman-setup        # Rootless Podman & Quadlets
just virtualization      # KVM/QEMU & Libvirt
just backup              # Create Niri & DMS backup
```
