# KDE Plasma Widgets and Customization

## Installation

```bash
just widgets
```

## Components

### Klipper (Clipboard)
- 100 items history
- Clipboard synchronization
- Persistent content

### KWin Tiling
- Window tiling with electric borders
- 4px padding between windows
- Border delay: 150ms

### Global Shortcuts
| Shortcut | Action |
|----------|--------|
| Meta+W | Toggle Overview |
| Meta+G | Toggle Grid View |
| Alt+Tab | Walk Through Windows |
| Meta+V | Klipper (history) |

### Plasmoids
- `kdeplasma-addons`: Official additional widgets
- `plasma-systemmonitor`: Native resource monitor
