# Widgets y Personalizacion de KDE Plasma

## Instalacion

```bash
just widgets
```

## Componentes

### Klipper (Portapapeles)
- Historial de 100 elementos
- Sincronizacion de portapapeles
- Contenido persistente

### KWin Tiling
- Mosaico de ventanas con bordes electricos
- Padding de 4px entre ventanas
- Retraso de borde: 150ms

### Atajos Globales
| Atajo | Accion |
|-------|--------|
| Meta+W | Toggle Overview |
| Meta+G | Toggle Grid View |
| Alt+Tab | Walk Through Windows |
| Meta+V | Klipper (historial) |

### Plasmoids
- `kdeplasma-addons`: Widgets adicionales oficiales
- `plasma-systemmonitor`: Monitor de recursos nativo
